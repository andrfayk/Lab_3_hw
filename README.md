# Домашнее задание к работе №3
Вариант 15

## Условие задачи
Написать и отладить программу пересчета числа световых лет в астрономические единицы.

## 1. Алгоритм и блок-схема
### Алгоритм:
1. Начало.
2. Объявить вещественные переменные:
- **ly** — расстояние в световых годах;
- **au** — то же расстояние в астрономических единицах.
3. Ввести ly.
4. Вычислить **au = ly · 63241.077** (в одном световом году 63241.077 астрономической единицы).
5. Вывести ly и au.
6. Конец.

## 2. Реализация программы
```c
#define _CRT_SECURE_NO_DEPRECATE
#include <stdio.h>
#include <locale.h>

// Вариант 15
// Пересчет числа световых лет в астрономические единицы
int main() {
    setlocale(LC_CTYPE, "RUS");
    double ly, au;
    puts("Введите число световых лет");
    scanf("%lf", &ly); // расстояние в световых годах
    au = ly * 63241.077; // в одном световом году 63241.077 астрономической единицы
    printf("%g св. лет = %.3f а. е.\n", ly, au);
    return 0;
}
```
